Git Branching

git checkout -b my-branch-name

It is used for creating and switching onto that branch.

git switch branch-name

It is used to switch to an already existing branch.

git switch -

This is the shorthand to switch between the previous branch and the current branch.

git merge branch-name

This is used to merge another branch into the current branch you’re on.

For example, you’re on the main branch, and you want to merge the dev branch (ahead of the main branch) onto main, then you would make sure you’re on the main branch and do:

git merge dev

And this way, you will merge the dev branch and sync it with the main branch unless you have merge conflicts.

git push origin branch-name

When you create a new branch locally, commit to it, and then merge it with another branch or just push this new branch onto your fork, with the above command you can do the same to upload the branch and its commits to the repo.

Stashing and Popping

git stash

This stashes your changes and keeps them locally, and this was a game-changer when I learned it, as you can stash your changes, merge the upcoming branch, then pop the stash, fix the merge conflicts, and continue working on your files without losing them.

git stash list

With this, you can view all the stashes you already had locally and later can pop them when needed.

git stash -m "my personalised message" --keep-index

With this, you can stash the unstaged changes with a personalized message, and --keep-index keeps the staged changes in your index while stashing the rest.

git stash pop

Above was all about how to stash and its options, and with git stash pop, you can actually pop your stashed changes after, for example, merging the main branch with the working branch for syncing.

git stash pop stash@{0}

It is specifically used to pop a specific stash in case you have many stashes available locally, and you can target and pop them with the stash name in the terminal.

Git Tracking

git remote -v

With this command, you can verify your origin URL and upstream URL, which is super important when working with an upstream repo or syncing changes.

git status

This command can be used to view the status of your current project, which shows your branch’s uncommitted changes along with untracked/new files to be committed.

Git Gems

git reset --soft HEAD~1

Remember when you committed a buggy feature locally but don’t know how to undo that commit? This is when this command becomes really handy — just make sure you are on the branch you want to undo the commit for.

git cherry-pick <commit hash>

This command is rarely used but very practical. Imagine when you have to migrate specific file changes from another branch onto your feature branch. You could go back to that old branch and commit to copying all the files, but this command can take that committed file change and attach it to your working branch — and honestly, it’s like magic.

Git Commands for Pros

When I discovered these commands, I literally felt like a pro. If you haven’t tried the gh command, then this is the time to learn it and up your terminal game:

gh pr create --base target-branch-name --fill

Remember when you push the branch and you have to go to the GitHub web interface to manually make a PR? With this command, you can automatically create a PR to the upstream repo… FROM YOUR TERMINAL!!!

gh pr merge --merge --delete-branch

What’s better than making a PR from your terminal? MERGING THE PR FROM YOUR TERMINAL! And with this command, you can do exactly that.
